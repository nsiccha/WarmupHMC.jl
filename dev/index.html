WarmupHMC.jl ​

WarmupHMC adapts NUTS with learned linear transformations and step sizes, plus optional partial centering for hierarchical models.

sh
git clone --branch dev https://github.com/nsiccha/WarmupHMC.jl
julia WarmupHMC.jl/scripts/install.jl

Sample a standard Gaussian with a supplied gradient:

julia
using WarmupHMC, Random
import LogDensityProblems as LDP

struct Gaussian end
LDP.dimension(::Gaussian) = 2
LDP.capabilities(::Type{Gaussian}) = LDP.LogDensityOrder{1}()
LDP.logdensity(::Gaussian, x) = -sum(abs2, x) / 2
LDP.logdensity_and_gradient(p::Gaussian, x) = (LDP.logdensity(p, x), -x)

result = adaptive_warmup_mcmc(Xoshiro(71), Gaussian();
    n_draws=1000, monitor_ess=true, progress=nothing)
size(result.posterior_position)

(2, 1000)

The result has one coordinate per row and one draw per column. This program's output is cached with a checked receipt; the build does not repeat the fit. Gaussian calibration shows its moments, diagnostics, figure, and reproduction commands.
